# Binary Converter

## Overview

The **Binary Converter** is a user-friendly application that allows you to convert text to binary and binary to text using a graphical user interface built with **Tkinter**. This application is designed to facilitate quick and easy conversions, making it ideal for developers, students, and anyone interested in binary encoding.

## Features

- **Text to Binary Conversion**: Input any text, and the application will convert it to its binary representation.
- **Binary to Text Conversion**: Input binary data, and the application will decode it back to readable text.
- **Graphical User Interface**: Built with Tkinter, the application provides an intuitive interface for users.
- **File Operations**: Open text files for conversion and save the output to a file.
- **Clipboard Support**: Copy the converted output directly to the clipboard for easy use.

## Requirements

To run this application, you need to have the following installed:

- **Python 3.x**: Ensure you have Python installed on your system.
- **Tkinter**: This library is typically included with Python installations. If not, you may need to install it separately.

## Installation

1. **Clone the Repository**: 
   ```bash
   git clone https://github.com/johnandrewsanvictores/Binary-Converter.git
   cd Binary-Converter
   ```

2. **Run the Application**: 
   Execute the following command in your terminal:
   ```bash
   python Binary_Converter(TKINTER).py
   ```

## Usage

1. **Input Text or Binary**: 
   - In the input text area, you can type or paste either text or binary data.
   - The application will automatically detect the type of input and convert it accordingly.

2. **Convert**: 
   - The conversion happens in real-time as you type. The output will be displayed in the output text area.

3. **Reset**: 
   - Use the "Reset" button to clear both input and output areas.

4. **Save Output**: 
   - You can save the output to a text file by clicking the "Save" button.

5. **Copy to Clipboard**: 
   - Use the "Copy to Clipboard" button to copy the output for use in other applications.

6. **Open File**: 
   - You can open a text file containing binary data, and the application will convert it to text automatically.

## Note on Tkinter

Due to differences in operating systems or versions of Windows, the alignment of elements in the Tkinter interface may vary. You may need to adjust the layout if you encounter any issues. The application is designed to be responsive, but testing on your specific OS is recommended.
